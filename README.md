# 🌾 CODE MAJOR – Crop Health & Drought Monitoring (GEE)

**CODE MAJOR** is a Google Earth Engine (GEE)-based project for **real-time crop health monitoring** and **drought risk assessment** focused on **Krishna District, Andhra Pradesh**, with comparative analysis in **Vidarbha, Maharashtra**.

---

## 🚀 Features

- 📈 NDVI & EVI Time-Series Charts (MODIS)
- 🌿 Crop Health Monitoring using Random Forest & CART
- 🌧️ Drought Risk Mapping (ET & Rainfall)
- 🔔 Real-Time Alert System *(In Progress)*
- 📊 Interactive Dashboard *(Planned)*

---

## 🛰️ Tech Stack

- **Platform:** Google Earth Engine
- **Data:** MODIS (NDVI, EVI, ET, Precipitation)
- **ML Models:** Random Forest, CART
- **Tools:** Firebase/SMS API (for alerts), GEE UI (dashboard)

---

## 📍 Focus Areas

- **AOI:** Krishna District (`table`)
- **Comparison:** Vidarbha Region
- **Scope:** Seasonal tracking, stress detection, drought alerts
